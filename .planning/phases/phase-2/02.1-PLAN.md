# Plan 2.1 — Corrigir Editor.tsx: Áudio por Cena + Pipeline State Sync

## Goal
O `Editor.tsx` lê dados corretos do pipeline — áudio por cena (não por capítulo) e cenas do `productionState` (persistidas no banco) em vez do `state.script` da memória local que pode estar desatualizado após auto-resume.

## Bugs Fixed
- **BUG-101** [critical] — `Editor.tsx:22` usa `ch.audioUrl` (áudio do capítulo inteiro) em vez de `s.audioUrl` (áudio da cena individual) — assembler nunca teve áudio real sincronizado
- **BUG-102** [high] — `Editor.tsx` lê `state.script?.chapters` do FactoryContext (estado em memória) — após auto-resume/refresh, `state.script` pode ser `null` mesmo com cenas prontas no banco
- **BUG-103** [medium] — `assembleVideo(scenes, null)` — `audioBlob` é sempre null; deveria ser `undefined` e o assembler gerenciar áudio por cena internamente via Web Audio

## Context

### BUG-101 — Áudio no nível errado
`narratorAgent.ts` gera `audioUrl` em `scene.audioUrl` (por cena individual).
`Editor.tsx:22` faz `audioUrl: ch.audioUrl` — lê o audioUrl do capítulo, que não existe (`VideoChapter.audioUrl` é opcional e nunca preenchido pelo narrator).
Resultado: todas as cenas chegam no assembler com `audioUrl: undefined`.

### BUG-102 — Estado stale após resume
Quando o usuário fecha e reabre a aba, o `productionState` (do banco) tem as cenas corretas com `imageUrl` e `audioUrl`.
Mas `state.script` do FactoryContext/pipelineOrchestrator é resetado para `INITIAL_STATE` (sem script).
O `Editor.tsx` usa `state.script?.chapters || []` → retorna `[]` → "Nenhuma cena disponível".

### BUG-103 — audioBlob null desnecessário
`useVideoAssembler.assembleVideo(scenes, audioBlob)` aceita um `audioBlob` global.
Mas a arquitetura correta é áudio por cena (cada cena tem seu `audioUrl`).
O `audioBlob` global é um artefato de uma versão anterior não implementada.

### Task 1: Corrigir fonte de cenas no Editor — usar productionState do banco (BUG-102)

**Arquivo:** `src/components/Factory/Editor.tsx`

**BEFORE (linhas 12-24):**
```typescript
export function Editor() {
  const { state, channelId } = useFactory();
  const { assembleVideo, assembling, progress, log } = useVideoAssembler();
  const [videoUrl, setVideoUrl] = useState<string | null>(null);

  const chapters = state.script?.chapters || [];
  const allScenes = chapters.flatMap(ch => 
    ch.scenes.map(s => ({
      ...s,
      chapterId: ch.id,
      audioUrl: ch.audioUrl // BUG: áudio do capítulo, não da cena
    }))
  ).filter(s => s.imageUrl);
```

**AFTER:**
```typescript
export function Editor() {
  const { state, channelId } = useFactory();
  const { assembleVideo, assembling, progress, log } = useVideoAssembler();
  const { state: productionState } = useProductionState(channelId);
  const [videoUrl, setVideoUrl] = useState<string | null>(null);

  // Preferir cenas do productionState (banco) sobre state.script (memória)
  // Isso garante que após auto-resume as cenas com imageUrl/audioUrl estejam disponíveis
  const scenesFromProduction = productionState?.scenes?.filter(
    s => s.imageUrl && s.status !== "error"
  ) ?? [];

  const scenesFromMemory = (state.script?.chapters ?? []).flatMap(ch =>
    ch.scenes.map(s => ({
      imageUrl: s.imageUrl,
      durationSec: s.durationSec || 5,
      subtitle: s.narration,
      audioUrl: s.audioUrl, // BUG-101 fix: usar s.audioUrl (cena), não ch.audioUrl
      emotion: (s as any).emotion || "neutral",
    }))
  ).filter(s => s.imageUrl);

  // Prioridade: banco > memória
  const allScenes: AssemblyScene[] = scenesFromProduction.length > 0
    ? scenesFromProduction.map(s => ({
        imageUrl: s.imageUrl!,
        durationSec: s.durationSec ?? 5,
        subtitle: undefined, // SceneSnapshot não tem narration — OK para montagem
        audioUrl: s.audioUrl,
        emotion: "neutral",
      }))
    : scenesFromMemory;
```
