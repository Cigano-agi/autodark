# Plan 2.3 — RemotionPreview: Áudio Real por Cena + Download Link no Pipeline Tab

## Goal
O preview usa o áudio TTS real (AI-33) de cada cena em vez de Web Speech API do browser. A aba Pipeline exibe um link direto para o Studio quando o pipeline conclui.

## Bugs Fixed
- **BUG-106** [high] — `RemotionPreview` usa `SpeechSynthesisUtterance` (browser TTS genérico) para narrar — ignora completamente o `audioUrl` por cena que está nos dados (linha 41-49)
- **BUG-107** [medium] — Quando pipeline conclui (`stage === "done"`), a UI não guia o operador para o Studio — ele não sabe que pode ir para `/channel/:id/studio`

## Context

### BUG-106 — Preview com browser TTS em vez de áudio real
`RemotionPreview.tsx` tem um sistema de `speakScene()` via `SpeechSynthesisUtterance`.
Isso ignora o `audioUrl` passado nas props. O componente recebe `slides[i].audioUrl` mas nunca usa.
O sistema de Web Speech API fala em português brasileiro hardcoded (`lang: "pt-BR"`) — errado para conteúdo em inglês/espanhol.

**Correção:** Usar `HTMLAudioElement` para tocar `slide.audioUrl` quando disponível, fallback para `SpeechSynthesis` apenas se `audioUrl` for undefined ou `"browser_tts"`.

### BUG-107 — Sem link para Studio após conclusão
`PipelineTab.tsx` e `ProductionWizard` não exibem um call-to-action para o Studio após `stage === "done"`.
O operador fica perdido — sabe que o pipeline concluiu mas não sabe onde o vídeo está.

### Task 1: Substituir SpeechSynthesis por HTMLAudioElement no RemotionPreview (BUG-106)

**Arquivo:** `src/remotion/RemotionPreview.tsx`

**BEFORE (linhas 22-50):**
```typescript
const speechRef = useRef<SpeechSynthesisUtterance | null>(null);
// ...
const speakScene = useCallback((sceneIndex: number) => {
  if (!("speechSynthesis" in window)) return;
  const scene = slides[sceneIndex];
  if (!scene?.narration) return;

  window.speechSynthesis.cancel();
  const utter = new SpeechSynthesisUtterance(scene.narration);
  utter.lang = "pt-BR";
  // ... etc
  window.speechSynthesis.speak(utter);
}, [slides]);
```

**AFTER:**
```typescript
const audioRef = useRef<HTMLAudioElement | null>(null);

const playScene = useCallback((sceneIndex: number) => {
  const scene = slides[sceneIndex];
  
  // Parar áudio anterior
  if (audioRef.current) {
    audioRef.current.pause();
    audioRef.current.currentTime = 0;
  }
  window.speechSynthesis?.cancel();

  // Áudio real via HTMLAudioElement (AI-33 TTS)
  if (scene?.audioUrl && scene.audioUrl !== "browser_tts") {
    const el = new Audio(scene.audioUrl);
    el.volume = 0.9;
    audioRef.current = el;
    el.play().catch(() => {
      // fallback silencioso se autoplay for bloqueado
    });
    return;
  }

  // Fallback: browser TTS apenas se não houver audioUrl real
  if (scene?.narration && "speechSynthesis" in window) {
    const utter = new SpeechSynthesisUtterance(scene.narration);
    // usar idioma configurado ou detectar do texto
    utter.rate = 0.95;
    window.speechSynthesis.speak(utter);
  }
}, [slides]);
```

Substituir todas as referências `speakScene` → `playScene` e `speechRef` → `audioRef`.

Atualizar cleanup no useEffect:
```typescript
const onPause = () => {

```
